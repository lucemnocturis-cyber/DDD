# Fonts for Dungeon Dice Duelists

## Required Fonts

Place a free TTF font file here for text rendering. Recommended options:

### Free Font Options:
1. **Roboto** - Clean, modern, highly readable
   - Download: https://fonts.google.com/specimen/Roboto
   - License: Apache 2.0

2. **Press Start 2P** - Retro pixel font for game aesthetic
   - Download: https://fonts.google.com/specimen/Press+Start+2P
   - License: Open Font License

3. **Source Sans Pro** - Professional sans-serif
   - Download: https://fonts.google.com/specimen/Source+Sans+Pro
   - License: Open Font License

4. **Orbitron** - Futuristic sci-fi style
   - Download: https://fonts.google.com/specimen/Orbitron
   - License: Open Font License

## File Naming
Once downloaded, rename the font file to one of these for automatic detection:
- `game_font.ttf` - Main game font
- `title_font.ttf` - For titles and headers
- `mono_font.ttf` - For numbers and stats

## Current Status
No font files currently installed. The game will use system default until fonts are added.
